# 🌌 Gravitational Wave Analysis Codes

This repository contains a collection of practice codes developed to explore the physics, data analysis, and visualization of gravitational waves. These scripts and notebooks focus on building intuition for signal processing, waveform modeling, and astrophysical interpretation.

📂 Contents

Waveform Modeling

Compact binary inspiral signals

Parameterized chirp generation

Time–frequency visualizations (spectrograms)

Data Analysis

Matched filtering with template banks

Noise characterization and whitening

Signal-to-noise ratio (SNR) estimation

Visualization

Strain data plots

Frequency–time evolution of GW signals

Comparison of injected vs. recovered waveforms

⚡ Features

Python scripts and Jupyter notebooks for interactive learning

Uses standard scientific and GW-related libraries:
numpy, scipy, matplotlib, gwpy, pycbc

Emphasis on clarity and reproducibility

🎓 Academic Context

These codes were created as practice exercises in gravitational-wave data analysis. While simplified compared to production-level pipelines (e.g., GstLAL, PyCBC, Bilby), they demonstrate the core principles behind real GW detections.
